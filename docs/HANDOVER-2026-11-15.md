## 2. 架构要点（读代码前先看这段）

### 2.1 载体（carrier）

| carrier | 含义 |
|---|---|
| `bundled` | 插件自带 Electron，`closeWithSession=false` 时可跨会话 |
| `chrome` / `edge` | 本机安装的浏览器；**现在使用用户真实 profile** |
| `sidebar` | 桌面端侧栏（需要 desktop bridge） |
| `panel`（surface，不是 carrier） | 只把页面放入 DSH 侧栏的同源代理 iframe，不创建浏览器会话 |

### 2.2 面（surface）与载体的区别

- `surface` 决定**页面出现在哪**：`panel` = DSH 侧栏；`builtin` = 真实浏览器窗口。
- `carrier` 决定**用哪个浏览器**：`bundled` / `edge` / `chrome` / `sidebar`。
- 两者独立：`channel=edge` + `surface=panel` 是日常形态（用你的浏览器内核，但页面进侧栏）。

### 2.3 关键代码位置

| 关注点 | 文件 |
|---|---|
| 同源代理（承载网页、改写链接、注入浮条） | `src/browser-electron/guest-route.ts` |
| 载体选择 / 用户 profile / 设置面板 | `src/browser-electron/entry.ts`、`settings-store.ts` |
| 系统浏览器启动、CDP、handoff、附着 | `src/browser-electron/system-browser.ts` |
| 工具的 schema 与前置校验 | `src/tool-browser/index.ts` |
| 引用采集与投递 | `src/browser-reference/*`、`client.js` |
| 客户端（浮条、轮询、放标签） | `client.js` |

## 3. 本次会话的实质性修复（按“预防优先”标准）

### 3.1 侧栏承载网页（需求 1）
新增 `GUEST_ROUTE`（`/dsh-builtin-browser/browser-view/guest?u=`），把目标页取回后改写链接、注入浮条脚本与 relay；
cookie 白名单回放（`FORWARD_COOKIE`）解决百度搜索结果页的反爬挑战。

### 3.2 文案去桌面化（需求 2）
`client.js` 中 `readiness.bridge.*` / `browser.sidebar` 等 8 条改为通用措辞（宿主进程 / 侧栏桥 / DSH 侧栏面板）。

### 3.3 单面策略（需求 4）
`dsh_browser_open` 新增 `surface: 'panel' | 'builtin'`：
`panel` 在创建会话之前返回占位（不建会话、不弹窗）；`builtin` 才走载体。
客户端仅在宿主回声 `surface === 'panel'` 时往侧栏放标签，两处叠加保证不会同页两开。

### 3.4 读取类工具不再启动浏览器（需求 7 的根因）
`ensureSession(..., create = false)`：除 `dsh_browser_open` 外，任何工具在无会话时直接报
「nothing is open in this task yet — call dsh_browser_open first」，不再拉起浏览器。
**修前**：`dsh_browser_state` 会触发 Edge 启动并 handoff（正是“反复重开”的根源）。

### 3.5 侧栏承载本机地址改为动作前拒绝（需求 8）
`assertSurfaceCanHost(surface, url)` 在 `browser.openUrl` **之前**抛错，并指明改用 `builtin`。
代理层另有 403 兜底（`isSelfTarget`：localhost / 127.* / ::1 / 10.* / 192.168.* / 172.16-31.*）。

### 3.6 用户真实 profile（需求 11）
`entry.ts` 中 `userProfileRoot(kind)`：edge → `%LOCALAPPDATA%\Microsoft\Edge\User Data`，
chrome → `...\Google\Chrome\User Data`，brave → `...\BraveSoftware\Brave-Browser\User Data`。
用户 profile 永不作为临时目录清理（`userProfile === undefined && !persist` 才清理）。

### 3.7 handoff 只开一个窗口（需求 15）
- 识别 exit code 0 = 交接给已运行实例；
- 附着等待从 8 000 ms 收紧到 1 200 ms（真正在启动的浏览器 ~450 ms 写出 `DevToolsActivePort`）；
- 工具侧把 handoff 判为成功并返回 `carrier: 'launched-user-profile'`，不报错、不重试。

### 3.8 附着用户正在用的 Edge（需求 14）
`adoptRunningBrowser(why, explicitPort?)` + `probeAttach(port=9222, 600ms)`：
启动前先问 `127.0.0.1:<port>/json/version`，探到即接入并置 `carrier = 'attached'`；
端口可用环境变量 `DSH_BROWSER_ATTACH_PORT` 覆盖。

### 3.9 两张技能卡（需求 9、10）
- `skills/dsh-debug-self/SKILL.md`：遇 bug 自助总结的方法（记观测不记推断、一次变一个变量、结论必须写成可复跑判据、**判据必须落在动作之前**）。
- `skills/dsh-debug-host/SKILL.md`：调试 DSH 用内置浏览器、为什么侧栏不能装 DSH、刷新≠重启、panel 模式的能力边界。

## 5. 环境与操作手册

### 5.1 实例

| 用途 | 端口 | 说明 |
|---|---|---|
| 用户日常宿主 | 3080 | `http://127.0.0.1:3080`，不要擅自重启 |
| 自测实例 | 3102 | `node apps/cli/lib/bin.js web --port 3102 --no-open`（**必须带 `--no-open`**，否则会拉起 Windows Edge Game Assist 且关不掉） |

### 5.2 设置文件

`D:\dsh-home\dsh-builtin-browser-host\settings.json`

当前值（日常形态）：

```json
"browser": { "channel": "edge", "headless": "auto", "surface": "panel" },
"ui": { "closeWithSession": false, "quiet": true }
```

- `channel`: `bundled` | `chrome` | `edge` | `sidebar` | `auto`
- `surface`（工具参数优先于它）: `panel`（只进侧栏）| `builtin`（真实浏览器）

### 5.3 热重载（不需要重启宿主）

```powershell
node scripts\hmr-touch.mjs --patch D:\dsh-home\profiles\web\cordis.patch.yml `
  --watch D:\dsh-legacy-archive\workspace-repos\freebuff-dsh-browser\lib
```

改 `src` 后跑 `tsc` 即可；监听脚本会触发插件重新组合。
**注意**：客户端 `client.js` 的改动需要刷新页面才生效（浏览器不会重新拉取）。

### 5.4 验证命令

```powershell
# 类型
node .\node_modules\typescript\bin\tsc -p tsconfig.json

# 全量测试
node --test "tests/*.test.mjs"

# 让 agent 可驱动你自己的 Edge（可选）
msedge.exe --remote-debugging-port=9222
```

### 5.5 判定载体实况

`dsh_browser_open` 的返回里带 `carrier`：

| 值 | 含义 |
|---|---|
| `bundled` | 插件自带 Electron |
| `attached` | 接管了你已启动且带调试端口的 Edge/Chrome |
| `launched-user-profile` | 用你的真实 profile 在你浏览器里新开（登录态在，但不可驱动） |
